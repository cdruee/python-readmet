Requirements:
-------------

    pip install numpy pandas

Installation:
-------------
As root or Administrator:

.. code-block:: bash

  pip install readmet

or as normal user:

.. code-block:: bash

  pip install --user readmet

or manually install the sources
available from `GitHub <https://github.com/cdruee/python-readmet>`_
